### 🧭 About

- 🦀 Most of my recent work is **Rust** — desktop apps with **Tauri**, CLIs, and log-crunching tools.
- 🧰 On the frontend side: **TypeScript**, React, Astro.
- 🐳 I run a small **Docker Swarm** homelab with Traefik in front of it — self-hosting is a hobby, not a chore.
- 🎯 Bias towards native binaries, boring infrastructure, and things that still work in five years.
